# Continumm service status and help

**Not launched. Public admission is disabled.**

Last manually checked: 22 October 2026.

The local implementation and test harnesses are under development. A live Render
service, Supabase ingress/storage/database, GitHub App authorization, managed
sandbox access and provider credentials have not been configured for release
qualification. There is no public availability commitment or completed live demo.

This document is hosted by GitHub independently of Render. If the application
is asleep, suspended or unavailable, check this page before retrying commands.
GitHub does not automatically redeliver failed webhook deliveries. The recovery
scanner can request bounded redelivery within GitHub's inspection history, and
records gaps it cannot recover. An older mutable comment is never treated as
new spending or approval intent; post a new command when a recorded history gap
requires it.

Never put model API keys, session tokens or private task details in issues or
comments. Use the authenticated console for private content once service setup
is complete. A submitted task or approval may have committed even if a response
was lost; use its existing identity and check authoritative state before creating
another request. An unknown publication outcome requires observation and
reconciliation, not repeated PR creation.

For setup or an incident, [open an issue in the project repository](https://github.com/marsh15/continumm/issues)
with the public error code, approximate UTC time and request ID. Do not attach
credentials, full prompts, repository archives or private logs. Project operators
will record meaningful incidents and resolution dates here manually.
