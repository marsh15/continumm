# Make browser actions and GitHub comments equivalent commands

The user requires both interfaces at launch. They normalize into the same command handlers, permission checks and durable transitions. A GitHub signature authenticates transport, not the authority of the comment author.

Created comments carry explicit run or approval identities; edits do not introduce new executable intent. Transport deduplication and logical-command deduplication are separate. This prevents a second interface from bypassing ownership, quota, expiry or exact approval.
