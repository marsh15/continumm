# Use a pausable free-tier deployment within the operator ceiling

The user confirmed a ₹1,000 monthly ceiling, personal non-commercial use, and acceptance of service pauses. Render Free, Supabase Free and Vercel Sandbox Hobby are the researched default bundle. The user requested a hosting revision but named no change; provider selection remains explicitly a planning default.

The application can suspend and resume durable work. A small dispatcher wakes the backend only for actionable work; it is not an idle keepalive. GitHub ingestion commits independently before acknowledgment because a sleeping backend may miss GitHub's response deadline.

This buys low operator cost at the expense of availability and very small public capacity. Actual account eligibility, non-overage behavior and deployed recovery are release gates. Paid fallback is prohibited without a new budget decision.
